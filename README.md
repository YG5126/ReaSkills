## Модуль B

Анализ безопасности банковского микросервиса для перевода средств и просмотра истории транзакций. В отчёте разобраны три приоритетные угрозы, их последствия для банка и меры защиты. Также описан порядок обработки уязвимостей от обнаружения до повторной проверки.

- **Архитектура.** [Схема потоков данных](./Module-B/DFD.png) показывает, как пользователь, API, PostgreSQL и Redis обмениваются данными.
- **Модель угроз.** [Редактируемая модель](./Module-B/Threat_Model.json) открывается в OWASP Threat Dragon. Для просмотра доступен [экспорт в PDF](./Module-B/Threat_Dragon_Report.pdf).
- **Статический анализ.** Проверка по [правилам Semgrep](./Module-B/semgrep_rules.yml) дала 10 срабатываний. Они сохранены в [результатах сканирования](./Module-B/semgrep_results.json). В [сводный файл](./Module-B/findings_with_idor.json) вручную добавлена находка IDOR.

## Модуль D

Расследование сетевой активности трояна STRRAT. Отчёт содержит хронологию событий, сведения о пострадавшей рабочей станции и признаки компрометации. Для проверки выводов откройте [исходный захват трафика](./Module-D/network.pcap) в Wireshark и перейдите к номерам кадров, указанным в отчёте.
