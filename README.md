# ReaSkills

Репозиторий объединяет отчёты и материалы по четырём модулям соревнований по информационной безопасности. Для каждого модуля отведена отдельная папка с именем вида `Module-D`. В ней хранятся итоговый отчёт, исходные файлы задания, скриншоты и другие материалы, на которые ссылается отчёт.

## Модуль D

Расследование сетевой активности трояна STRRAT. Отчёт содержит хронологию событий, сведения о пострадавшей рабочей станции и признаки компрометации. Для проверки выводов откройте [исходный захват трафика](./Module-D/network.pcap) в Wireshark и перейдите к номерам кадров, указанным в отчёте.

## Как добавить следующий модуль

1. Создайте в корне репозитория папку `Module-<буква>`.
2. Поместите в неё отчёт и все связанные с ним файлы. Если скриншотов много, их удобно собрать в подпапке `screenshots/`.
3. Добавьте в таблицу «Модули» строку с темой и относительными ссылками на папку и отчёт.
